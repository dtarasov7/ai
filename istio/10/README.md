# 10. Разрешение имён

[Практический разбор: что даёт Istio и что остаётся в сервисе](АНАЛИЗ.md).

**Можно:** Частично. **Рекомендация:** Kubernetes DNS — основа; Istio по необходимости.

## Что означает правый столбец

На скриншоте: `Service Registry`.

Service Registry хранит известные mesh сервисы, но не равен DNS-серверу. Имена *.svc обычно разрешает CoreDNS. Istio DNS capture/proxy может перехватывать запросы и обслуживать некоторые ServiceEntry; поддержка и настройки зависят от версии и режима.

## Плюсы, минусы и границы ответственности

Плюс DNS capture: специальные имена mesh и сокращение DNS-запросов. Минус: дополнительные правила разрешения, конфликты и усложнение диагностики.

Добавление ServiceEntry само по себе не гарантирует DNS-ответ приложению. Для базового service discovery не нужно заменять CoreDNS. Сценарии используют sidecar и не включают DNS capture глобально.

Источник: [документация механизма](https://istio.io/latest/docs/ops/configuration/traffic-management/dns/).
Версию/редакцию Deckhouse и условия стенда проверяют по [общему README](../README.md).

## Испытание и критерий

Проверяем разрешение demo.<namespace>.svc.cluster.local в ClusterIP и успешный HTTP через это имя, а также NXDOMAIN для отсутствующего Service. Это совместимость с Kubernetes DNS; отдельный опыт 13 показывает регистрацию внешнего адреса без DNS capture.

`01-prepare.sh` создаёт изолированные тестовые ресурсы; `02-check.sh` проверяет
заявленный сценарий; `03-cleanup.sh` удаляет namespace `pmi-istio-10` после проверки
метки владельца. Все три файла запускаются независимо через Bash, из любого каталога.
Порядок: prepare → check → сохранение результатов → cleanup. После неудачи сначала
сохраните диагностику, затем выполните cleanup. См. общие предпосылки и коды выхода.

```bash
bash 01-prepare.sh
bash 02-check.sh
bash 03-cleanup.sh
```

Для протокола сохраните версию DKP/Istio, kube-context, образы с digest, вывод команд,
HTTP-результаты и `kubectl -n pmi-istio-10 get pods,svc -o wide`.
Сценарий создан для испытания; фактическое прохождение на Deckhouse пока не подтверждено.

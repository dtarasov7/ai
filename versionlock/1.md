Да. Ниже я бы уже использовал этот вариант как рабочий. Он рассчитан на **ansible-core 2.13**, **Python 3.8 на РЕД ОС 7.3**, десятки серверов и десятки пакетов. Python 3.8 входит в поддерживаемый диапазон target Python для ansible-core 2.13. :chatgpt-content-reference{index="0"}

На РЕД ОС 7.3 `versionlock` предоставляется пакетом `python3-dnf-plugin-versionlock`; штатная проверка — `dnf versionlock list`. :chatgpt-content-reference{index="1"}

```yaml
---
###############################################################################
#
# Проверка versionlock на серверах РЕД ОС 7.3
#
# Требования:
#   ansible-core 2.13
#   Python 3.8 на managed hosts
#
# Что делает playbook:
#
#   1. Проверяет, был ли установлен python3-dnf-plugin-versionlock.
#   2. Если нет — пытается установить его.
#   3. Запоминает исходное состояние.
#   4. Проверяет работоспособность dnf versionlock.
#   5. Один раз получает ВСЮ RPM database.
#   6. Один раз получает ВСЕ versionlock rules.
#   7. Проверяет только packages_to_check.
#   8. Учитывает:
#        - пакеты, установленные через rpm;
#        - несколько версий одного RPM;
#        - несколько архитектур;
#        - wildcard versionlock, например .*
#   9. Формирует единый CSV на Ansible controller.
#
###############################################################################


###############################################################################
# PLAY 1
#
# Сбор информации с серверов
###############################################################################

- name: Audit RPM packages and DNF versionlock
  hosts: all
  gather_facts: false
  become: true

  vars:

    ###########################################################################
    # Список проверяемых RPM package names
    #
    # ВАЖНО:
    # указываются именно RPM NAME, а не имя бинарника/сервиса.
    ###########################################################################

    packages_to_check:
      - nginx
      - openssl
      - curl
      - java-11-openjdk
      - postgresql
      - httpd
      - python3

    ###########################################################################
    # Пакет versionlock для РЕД ОС 7.3
    ###########################################################################

    versionlock_package: python3-dnf-plugin-versionlock

    ###########################################################################
    # true:
    #   если plugin отсутствует — попытаться установить.
    #
    # false:
    #   только аудит, никаких изменений системы.
    ###########################################################################

    versionlock_install_if_missing: true


  tasks:

    ###########################################################################
    #
    # VERSIONLOCK PLUGIN
    #
    ###########################################################################

    - name: Check whether versionlock plugin was installed before audit
      ansible.builtin.command:
        argv:
          - rpm
          - -q
          - "{{ versionlock_package }}"
      register: versionlock_pkg_before
      changed_when: false
      failed_when: false


    ###########################################################################
    # Сохраняем ИСХОДНОЕ состояние.
    #
    # Оно останется в отчете даже в случае успешной установки plugin.
    ###########################################################################

    - name: Save initial versionlock plugin state
      ansible.builtin.set_fact:
        versionlock_was_installed: >-
          {{
            versionlock_pkg_before.rc == 0
          }}

        versionlock_install_attempted: >-
          {{
            versionlock_pkg_before.rc != 0
            and
            versionlock_install_if_missing | bool
          }}


    ###########################################################################
    # Если plugin отсутствует — устанавливаем.
    #
    # failed_when: false принципиален:
    #
    # если на одном сервере:
    #   - недоступен repository;
    #   - проблема DNS;
    #   - dnf lock;
    #   - отсутствует пакет;
    #
    # остальные серверы всё равно должны быть проверены.
    ###########################################################################

    - name: Install versionlock plugin if missing
      ansible.builtin.dnf:
        name: "{{ versionlock_package }}"
        state: present
      register: versionlock_install
      when:
        - versionlock_pkg_before.rc != 0
        - versionlock_install_if_missing | bool
      failed_when: false


    ###########################################################################
    # Независимо от результата установки снова смотрим RPM DB.
    ###########################################################################

    - name: Check versionlock plugin after optional installation
      ansible.builtin.command:
        argv:
          - rpm
          - -q
          - "{{ versionlock_package }}"
      register: versionlock_pkg_after
      changed_when: false
      failed_when: false


    - name: Save final versionlock plugin state
      ansible.builtin.set_fact:

        versionlock_is_installed: >-
          {{
            versionlock_pkg_after.rc == 0
          }}

        versionlock_install_success: >-
          {{
            (
              versionlock_pkg_before.rc != 0
              and
              versionlock_install_if_missing | bool
              and
              versionlock_pkg_after.rc == 0
            )
          }}


    ###########################################################################
    # Определяем статус установки для удобства CSV.
    ###########################################################################

    - name: Determine versionlock install status
      ansible.builtin.set_fact:
        versionlock_install_status: >-
          {%- if versionlock_was_installed -%}
          already_installed
          {%- elif not (versionlock_install_if_missing | bool) -%}
          not_requested
          {%- elif versionlock_is_installed -%}
          installed
          {%- else -%}
          install_failed
          {%- endif -%}


    ###########################################################################
    #
    # VERSIONLOCK LIST
    #
    # Проверяем не только наличие RPM plugin, но и то,
    # что команда реально работает.
    #
    ###########################################################################

    - name: Read DNF versionlock list
      ansible.builtin.command:
        argv:
          - dnf
          - -q
          - versionlock
          - list
      register: versionlock_query
      changed_when: false
      failed_when: false
      when:
        - versionlock_is_installed


    ###########################################################################
    # versionlock_available=yes означает:
    #
    # plugin установлен И команда dnf versionlock list успешно работает.
    #
    ###########################################################################

    - name: Determine whether versionlock is operational
      ansible.builtin.set_fact:

        versionlock_available: >-
          {{
            versionlock_is_installed
            and
            (versionlock_query.rc | default(1)) == 0
          }}

        versionlock_lines: >-
          {{
            versionlock_query.stdout_lines
            | default([])
            | map('trim')
            | reject('equalto', '')
            | list
          }}


    ###########################################################################
    #
    # RPM DATABASE
    #
    # Один rpm -qa на сервер независимо от количества packages_to_check.
    #
    ###########################################################################

    - name: Read complete RPM database
      ansible.builtin.command:
        argv:
          - rpm
          - -qa
          - --qf
          - "%{NAME}|%{EPOCHNUM}|%{VERSION}|%{RELEASE}|%{ARCH}\n"
      register: rpm_db
      changed_when: false
      failed_when: false


    ###########################################################################
    # Проверяем, удалось ли прочитать RPM DB.
    ###########################################################################

    - name: Save RPM database state
      ansible.builtin.set_fact:
        rpm_database_available: "{{ rpm_db.rc == 0 }}"


    ###########################################################################
    #
    # АНАЛИЗ
    #
    # Выполняется ОДНИМ Python-процессом.
    #
    # Для каждого пакета НЕ запускаются rpm/dnf.
    #
    ###########################################################################

    - name: Build package audit
      ansible.builtin.shell: |
        /usr/bin/python3 <<'PY'

        import fnmatch
        import json


        # --------------------------------------------------------------------
        # Входные данные из Ansible
        # --------------------------------------------------------------------

        packages_to_check = json.loads(
            r'''{{ packages_to_check | to_json }}'''
        )

        rpm_lines = json.loads(
            r'''{{ rpm_db.stdout_lines | default([]) | to_json }}'''
        )

        lock_lines = json.loads(
            r'''{{ versionlock_lines | default([]) | to_json }}'''
        )

        versionlock_available = json.loads(
            r'''{{ versionlock_available | bool | to_json }}'''
        )


        # --------------------------------------------------------------------
        # RPM database
        #
        # installed:
        #
        # {
        #     "nginx": [
        #         {
        #             "name": "nginx",
        #             "epoch": "0",
        #             ...
        #         }
        #     ]
        # }
        # --------------------------------------------------------------------

        installed = {}

        for line in rpm_lines:

            try:
                name, epoch, version, release, arch = line.split("|", 4)
            except ValueError:
                continue

            nevra = (
                name
                + "-"
                + epoch
                + ":"
                + version
                + "-"
                + release
                + "."
                + arch
            )

            item = {
                "name": name,
                "epoch": epoch,
                "version": version,
                "release": release,
                "arch": arch,
                "nevra": nevra,
            }

            installed.setdefault(name, []).append(item)


        # --------------------------------------------------------------------
        # Versionlock rules
        #
        # Возможный вариант:
        #
        # nginx-0:1.20.1-10.el7.*
        #
        # Также versionlock может содержать !rule.
        #
        # !rule сохраняем отдельно:
        # это exclude rule, а не обычный positive version lock.
        # --------------------------------------------------------------------

        locks = []

        for line in lock_lines:

            line = line.strip()

            if not line:
                continue

            # Отбрасываем очевидный служебный вывод DNF.
            if line.startswith("Last metadata"):
                continue

            if line.startswith(
                "Последняя проверка"
            ):
                continue

            excluded = line.startswith("!")

            if excluded:
                pattern = line[1:]
            else:
                pattern = line

            locks.append({
                "raw": line,
                "pattern": pattern,
                "excluded": excluded,
            })


        # --------------------------------------------------------------------
        # Проверяем packages_to_check
        # --------------------------------------------------------------------

        result = []


        for package_name in packages_to_check:

            rpms = installed.get(package_name, [])


            # ----------------------------------------------------------------
            # Находим ВСЕ правила, относящиеся к package_name.
            #
            # Это позволяет увидеть ситуацию:
            #
            # versionlock для nginx присутствует,
            # но установленная версия nginx ему не соответствует.
            # ----------------------------------------------------------------

            package_rules = []
            positive_package_rules = []
            exclude_package_rules = []

            if versionlock_available:

                prefix = package_name + "-"

                for lock in locks:

                    if lock["pattern"].startswith(prefix):

                        package_rules.append(lock["raw"])

                        if lock["excluded"]:
                            exclude_package_rules.append(
                                lock["raw"]
                            )
                        else:
                            positive_package_rules.append(
                                lock["raw"]
                            )


            # ----------------------------------------------------------------
            # Пакет НЕ установлен
            # ----------------------------------------------------------------

            if not rpms:

                if versionlock_available:
                    configured = bool(package_rules)
                else:
                    configured = None

                result.append({

                    "package": package_name,

                    "installed": False,

                    "epoch": "",
                    "version": "",
                    "release": "",
                    "arch": "",
                    "nevra": "",

                    "versionlock_configured": configured,

                    # Нет установленной версии, поэтому N/A.
                    "installed_version_locked": None,

                    "versionlock_rule": ",".join(
                        positive_package_rules
                    ),

                    "versionlock_exclude_rule": ",".join(
                        exclude_package_rules
                    ),
                })

                continue


            # ----------------------------------------------------------------
            # Пакет установлен.
            #
            # Может существовать:
            #
            #   - несколько версий kernel;
            #   - x86_64 + i686;
            #   - несколько RPM с одинаковым NAME.
            #
            # Поэтому на каждую установленную NEVRA отдельная строка CSV.
            # ----------------------------------------------------------------

            for rpm in rpms:

                matched_rules = []

                if versionlock_available:

                    for lock in locks:

                        # !rule не считаем обычным version lock.
                        if lock["excluded"]:
                            continue

                        if fnmatch.fnmatchcase(
                            rpm["nevra"],
                            lock["pattern"]
                        ):
                            matched_rules.append(
                                lock["raw"]
                            )


                if versionlock_available:

                    configured = bool(
                        package_rules
                    )

                    installed_version_locked = bool(
                        matched_rules
                    )

                else:

                    # None => UNKNOWN,
                    # а не false/no.
                    configured = None
                    installed_version_locked = None


                result.append({

                    "package": package_name,

                    "installed": True,

                    "epoch": rpm["epoch"],
                    "version": rpm["version"],
                    "release": rpm["release"],
                    "arch": rpm["arch"],
                    "nevra": rpm["nevra"],

                    "versionlock_configured":
                        configured,

                    "installed_version_locked":
                        installed_version_locked,

                    "versionlock_rule":
                        ",".join(positive_package_rules),

                    "versionlock_exclude_rule":
                        ",".join(exclude_package_rules),
                })


        print(
            json.dumps(
                result,
                ensure_ascii=False
            )
        )

        PY

      args:
        executable: /bin/bash

      register: audit_json

      changed_when: false

      failed_when: false

      when:
        - rpm_database_available


    ###########################################################################
    # Python JSON -> Ansible variable
    ###########################################################################

    - name: Save package audit data
      ansible.builtin.set_fact:

        versionlock_audit: >-
          {{
            audit_json.stdout | from_json
          }}

      when:
        - rpm_database_available
        - audit_json.rc | default(1) == 0


    ###########################################################################
    #
    # HOST STATUS
    #
    ###########################################################################

    - name: Determine audit host status
      ansible.builtin.set_fact:

        versionlock_host_status: >-
          {%- if not rpm_database_available -%}
          rpm_database_error
          {%- elif versionlock_audit is not defined -%}
          audit_error
          {%- elif not versionlock_is_installed -%}
          versionlock_not_installed
          {%- elif not versionlock_available -%}
          versionlock_error
          {%- else -%}
          ok
          {%- endif -%}


###############################################################################
#
# PLAY 2
#
# Создание единого отчета.
#
# Выполняется только на Ansible controller.
#
# Поэтому нет проблемы одновременной записи нескольких fork в один CSV.
#
###############################################################################

- name: Generate central versionlock CSV report
  hosts: localhost
  gather_facts: false
  become: false

  vars:

    report_dir: "./reports"

    report_file: "./reports/versionlock_report.csv"


  tasks:

    ###########################################################################
    # Каталог reports
    ###########################################################################

    - name: Create report directory
      ansible.builtin.file:
        path: "{{ report_dir }}"
        state: directory
        mode: "0755"


    ###########################################################################
    # Создаем CSV полностью за один проход.
    #
    # Разделитель ;
    ###########################################################################

    - name: Generate versionlock CSV report
      ansible.builtin.copy:

        dest: "{{ report_file }}"

        mode: "0644"

        content: |
          host;host_status;package;installed;epoch;version;release;arch;nevra;versionlock_was_installed;versionlock_install_status;versionlock_is_installed;versionlock_available;versionlock_configured;installed_version_locked;versionlock_rule;versionlock_exclude_rule
          {% for host in groups['all'] | sort %}
          {% if hostvars[host].versionlock_audit is defined %}
          {% for p in hostvars[host].versionlock_audit %}
          {{ host }};{{ hostvars[host].versionlock_host_status | default('unknown') }};{{ p.package }};{{ 'yes' if p.installed else 'no' }};{{ p.epoch }};{{ p.version }};{{ p.release }};{{ p.arch }};{{ p.nevra }};{{ 'yes' if hostvars[host].versionlock_was_installed | default(false) else 'no' }};{{ hostvars[host].versionlock_install_status | default('unknown') }};{{ 'yes' if hostvars[host].versionlock_is_installed | default(false) else 'no' }};{{ 'yes' if hostvars[host].versionlock_available | default(false) else 'no' }};{% if p.versionlock_configured is none %}unknown{% elif p.versionlock_configured %}yes{% else %}no{% endif %};{% if p.installed_version_locked is none %}{% if p.installed %}unknown{% else %}n/a{% endif %}{% elif p.installed_version_locked %}yes{% else %}no{% endif %};{{ p.versionlock_rule | replace(';', ',') }};{{ p.versionlock_exclude_rule | replace(';', ',') }}
          {% endfor %}
          {% else %}
          {{ host }};{{ hostvars[host].versionlock_host_status | default('unreachable_or_failed') }};;;;;;;;;;;;;;;
          {% endif %}
          {% endfor %}


    ###########################################################################
    # Показываем путь
    ###########################################################################

    - name: Show report location
      ansible.builtin.debug:
        msg: "Versionlock report created: {{ report_file }}"
```

### Что означают ключевые столбцы

В итоговом CSV я специально разделил несколько понятий.

`versionlock_was_installed` показывает состояние **до запуска playbook**. Поэтому если Ansible установил плагин сам, эта информация не потеряется.

`versionlock_install_status` может иметь значения:

```text
already_installed
installed
install_failed
not_requested
```

`versionlock_available` означает, что недостаточно просто наличия RPM `python3-dnf-plugin-versionlock` — реально успешно выполнился:

```bash
dnf -q versionlock list
```

Это полезно, например, если RPM установлен, но сам plugin сломан или есть проблема с DNF.

### Два разных признака versionlock

Я добавил два столбца, потому что это диагностически намного полезнее.

Например:

```text
versionlock_configured=yes
installed_version_locked=yes
```

означает: для `nginx` существует правило versionlock и установленная версия действительно попадает под него.

А:

```text
versionlock_configured=yes
installed_version_locked=no
```

означает: **правило для nginx существует, но установленная сейчас NEVRA под него не попадает**.

Например:

```text
installed:
nginx-0:1.20.1-10.el7.x86_64

versionlock:
nginx-0:1.18.0-5.el7.*
```

Результат:

```text
versionlock_configured=yes
installed_version_locked=no
```

Это важное отличие, которое простой `grep nginx` не обнаруживает.

Versionlock РЕД ОС действительно может содержать wildcard, например официальный пример показывает записи вида `php-0:7.4.11-2.el7.*`. :chatgpt-content-reference{index="2"}

### Если пакет вообще отсутствует

Получится примерно:

```text
package=nginx
installed=no
versionlock_configured=no
installed_version_locked=n/a
```

Но возможна и ситуация:

```text
package=nginx
installed=no
versionlock_configured=yes
installed_version_locked=n/a
```

То есть RPM уже удалили, а правило versionlock осталось.

### Если versionlock проверить невозможно

Например, установка plugin не удалась:

```text
versionlock_install_status=install_failed
versionlock_is_installed=no
versionlock_available=no
versionlock_configured=unknown
installed_version_locked=unknown
```

Именно `unknown`, а не `no`. Это позволяет потом отфильтровать серверы, где проверка на самом деле не была выполнена.

### Если программа была установлена через `rpm -i`

Она будет найдена, потому что список программ берётся напрямую из RPM DB:

```bash
rpm -qa
```

Способ установки не имеет значения.

Если программа установлена из `tar.gz`, исходников или просто скопирована в `/opt`, она не является RPM-пакетом и `dnf versionlock` к ней неприменим.

### Inventory

Для вашей среды с Python 3.8 я бы зафиксировал интерпретатор явно:

```ini
[redos]
srv01 ansible_host=10.10.10.11
srv02 ansible_host=10.10.10.12
srv03 ansible_host=10.10.10.13

[redos:vars]
ansible_python_interpreter=/usr/bin/python3
```

Ansible-core 2.13 поддерживает Python 3.5–3.10 на managed nodes, поэтому Python 3.8 здесь подходит штатно. :chatgpt-content-reference{index="3"}

Запуск:

```bash
ansible-playbook \
  -i inventory.ini \
  check_versionlock.yml
```

После этого:

```text
./reports/versionlock_report.csv
```

Например:

```text
host;host_status;package;installed;...;versionlock_was_installed;versionlock_install_status;versionlock_is_installed;versionlock_available;versionlock_configured;installed_version_locked;versionlock_rule
srv01;ok;nginx;yes;...;yes;already_installed;yes;yes;yes;yes;nginx-0:1.20.1-10.el7.*
srv01;ok;openssl;yes;...;yes;already_installed;yes;yes;no;no;
srv02;ok;nginx;yes;...;no;installed;yes;yes;no;no;
srv03;versionlock_not_installed;nginx;yes;...;no;install_failed;no;no;unknown;unknown;
```

И ещё практический момент: установка plugin через `ansible.builtin.dnf` здесь предпочтительнее `yum`. В документации Ansible 2.13 отдельно указано, что модуль `yum` требует Python 2, а при Python 3 следует использовать `ansible.builtin.dnf`. :chatgpt-content-reference{index="4"}

Да, здесь стоит упростить архитектуру.

1. **Два play действительно не нужны.** Я разделил их, чтобы гарантировать централизованное формирование файла после обработки хостов, но при стандартной стратегии Ansible `linear` достаточно последней задачи с `delegate_to: localhost`, `become: false`, `run_once: true`.

2. Причина появления всех серверов найдена точно: я использовал `groups['all']`. Эта переменная означает **весь inventory**, независимо от `--limit`. Поэтому серверы вне limit попадали в цикл, но фактов `versionlock_audit` у них не было, после чего мой шаблон ошибочно подписывал их как `unreachable_or_failed`. Они вовсе не обязательно были unreachable. В исправленном варианте используется `ansible_play_hosts` — только реально участвующие и оставшиеся активными хосты текущего запуска.

3. Отсутствующие RPM больше вообще не попадают в результат. Если на сервере из списка найдено 3 пакета из 50 — в CSV будет ровно 3 строки для этого сервера.

Ниже исправленный итоговый вариант.

```yaml
---
###############################################################################
#
# Audit DNF versionlock
#
# Target:
#   RED OS 7.3
#   ansible-core 2.13
#   Python 3.8
#
# Особенности:
#
#   - один play;
#   - поддерживает --limit;
#   - отсутствующие packages_to_check в CSV НЕ выводятся;
#   - versionlock plugin при отсутствии устанавливается;
#   - сохраняется информация, был ли plugin установлен до запуска;
#   - один rpm -qa на сервер;
#   - один dnf versionlock list на сервер;
#   - итоговый CSV создается на Ansible controller;
#   - несколько версий одного RPM выводятся отдельными строками.
#
###############################################################################

- name: Audit RPM packages and DNF versionlock
  hosts: all
  gather_facts: false
  become: true

  vars:

    ###########################################################################
    # Проверяемые RPM NAME
    ###########################################################################

    packages_to_check:
      - nginx
      - openssl
      - curl
      - java-11-openjdk
      - postgresql
      - httpd
      - python3

    ###########################################################################
    # Versionlock для RED OS 7.3
    ###########################################################################

    versionlock_package: python3-dnf-plugin-versionlock

    ###########################################################################
    # true  - установить plugin при отсутствии
    # false - только проверить
    ###########################################################################

    versionlock_install_if_missing: true

    ###########################################################################
    # Итоговый файл НА ANSIBLE CONTROLLER
    ###########################################################################

    report_dir: "./reports"
    report_file: "./reports/versionlock_report.csv"


  tasks:

    ###########################################################################
    #
    # 1. ПРОВЕРЯЕМ ИСХОДНОЕ СОСТОЯНИЕ VERSIONLOCK
    #
    ###########################################################################

    - name: Check whether versionlock plugin was installed before audit
      ansible.builtin.command:
        argv:
          - rpm
          - -q
          - "{{ versionlock_package }}"
      register: versionlock_pkg_before
      changed_when: false
      failed_when: false


    - name: Save initial versionlock state
      ansible.builtin.set_fact:

        versionlock_was_installed: >-
          {{
            versionlock_pkg_before.rc == 0
          }}

        versionlock_install_attempted: >-
          {{
            versionlock_pkg_before.rc != 0
            and
            versionlock_install_if_missing | bool
          }}


    ###########################################################################
    #
    # 2. ЕСЛИ НЕТ — ПЫТАЕМСЯ УСТАНОВИТЬ
    #
    # failed_when: false:
    #
    # проблема репозитория на одном сервере не должна останавливать аудит
    # остальных серверов.
    #
    ###########################################################################

    - name: Install versionlock plugin if missing
      ansible.builtin.dnf:
        name: "{{ versionlock_package }}"
        state: present
      register: versionlock_install_result
      when:
        - versionlock_pkg_before.rc != 0
        - versionlock_install_if_missing | bool
      failed_when: false


    ###########################################################################
    #
    # 3. ПОВТОРНО ПРОВЕРЯЕМ НАЛИЧИЕ PLUGIN
    #
    ###########################################################################

    - name: Check versionlock plugin after optional installation
      ansible.builtin.command:
        argv:
          - rpm
          - -q
          - "{{ versionlock_package }}"
      register: versionlock_pkg_after
      changed_when: false
      failed_when: false


    - name: Determine versionlock installation status
      ansible.builtin.set_fact:

        versionlock_is_installed: >-
          {{
            versionlock_pkg_after.rc == 0
          }}

        versionlock_install_status: >-
          {%- if versionlock_pkg_before.rc == 0 -%}
          already_installed
          {%- elif not (versionlock_install_if_missing | bool) -%}
          not_requested
          {%- elif versionlock_pkg_after.rc == 0 -%}
          installed
          {%- else -%}
          install_failed
          {%- endif -%}


    ###########################################################################
    #
    # 4. ПОЛУЧАЕМ VERSIONLOCK
    #
    # Выполняется только если plugin установлен.
    #
    ###########################################################################

    - name: Read DNF versionlock list
      ansible.builtin.command:
        argv:
          - dnf
          - -q
          - versionlock
          - list
      register: versionlock_query
      changed_when: false
      failed_when: false
      when:
        - versionlock_is_installed | bool


    ###########################################################################
    # Plugin может быть установлен, но сама команда может не работать.
    ###########################################################################

    - name: Determine whether versionlock is operational
      ansible.builtin.set_fact:

        versionlock_available: >-
          {{
            versionlock_is_installed | bool
            and
            (versionlock_query.rc | default(1)) == 0
          }}

        versionlock_lines: >-
          {{
            versionlock_query.stdout_lines
            | default([])
            | map('trim')
            | reject('equalto', '')
            | list
          }}


    ###########################################################################
    #
    # 5. ОДИН РАЗ ЧИТАЕМ ВСЮ RPM DATABASE
    #
    # Способ установки пакета значения не имеет:
    #
    #   dnf install
    #   yum install
    #   rpm -i
    #
    # всё это будет видно через rpm -qa.
    #
    ###########################################################################

    - name: Read complete RPM database
      ansible.builtin.command:
        argv:
          - rpm
          - -qa
          - --qf
          - "%{NAME}|%{EPOCHNUM}|%{VERSION}|%{RELEASE}|%{ARCH}\n"
      register: rpm_db
      changed_when: false
      failed_when: false


    - name: Save RPM database status
      ansible.builtin.set_fact:
        rpm_database_available: "{{ rpm_db.rc == 0 }}"


    ###########################################################################
    #
    # 6. АНАЛИЗИРУЕМ RPM + VERSIONLOCK
    #
    # ВАЖНО:
    #
    # В result добавляются ТОЛЬКО реально установленные пакеты
    # из packages_to_check.
    #
    # Если nginx отсутствует — строки nginx для данного сервера не будет.
    #
    ###########################################################################

    - name: Build package versionlock audit
      ansible.builtin.shell: |
        /usr/bin/python3 <<'PY'

        import fnmatch
        import json


        # ====================================================================
        # Input
        # ====================================================================

        packages_to_check = set(
            json.loads(
                r'''{{ packages_to_check | to_json }}'''
            )
        )

        rpm_lines = json.loads(
            r'''{{ rpm_db.stdout_lines | default([]) | to_json }}'''
        )

        lock_lines = json.loads(
            r'''{{ versionlock_lines | default([]) | to_json }}'''
        )

        versionlock_available = json.loads(
            r'''{{ versionlock_available | bool | to_json }}'''
        )


        # ====================================================================
        # Versionlock rules
        # ====================================================================

        locks = []

        for line in lock_lines:

            line = line.strip()

            if not line:
                continue

            # Служебный вывод dnf нам не нужен.
            if line.startswith("Last metadata"):
                continue

            if line.startswith("Последняя проверка"):
                continue

            excluded = line.startswith("!")

            if excluded:
                pattern = line[1:]
            else:
                pattern = line

            locks.append({
                "raw": line,
                "pattern": pattern,
                "excluded": excluded,
            })


        # ====================================================================
        # RPM DB
        #
        # Сразу игнорируем всё, чего нет в packages_to_check.
        #
        # Поэтому размер результата зависит не от rpm -qa,
        # а от реально найденных интересующих пакетов.
        # ====================================================================

        result = []


        for line in rpm_lines:

            try:
                name, epoch, version, release, arch = line.split("|", 4)
            except ValueError:
                continue


            # ---------------------------------------------------------------
            # Этот пакет нас вообще не интересует.
            # ---------------------------------------------------------------

            if name not in packages_to_check:
                continue


            # ---------------------------------------------------------------
            # Полный NEVRA
            # ---------------------------------------------------------------

            nevra = (
                name
                + "-"
                + epoch
                + ":"
                + version
                + "-"
                + release
                + "."
                + arch
            )


            # ---------------------------------------------------------------
            # Ищем versionlock именно для установленной NEVRA.
            #
            # Например:
            #
            # installed:
            #   nginx-0:1.20.1-10.el7.x86_64
            #
            # versionlock:
            #   nginx-0:1.20.1-10.el7.*
            #
            # fnmatch => match.
            # ---------------------------------------------------------------

            matched_rules = []


            if versionlock_available:

                for lock in locks:

                    # !rule является exclude rule.
                    # Его не считаем обычным version lock.
                    if lock["excluded"]:
                        continue

                    if fnmatch.fnmatchcase(
                        nevra,
                        lock["pattern"]
                    ):
                        matched_rules.append(
                            lock["raw"]
                        )


            # ---------------------------------------------------------------
            # None означает:
            #
            # проверить невозможно.
            #
            # Это принципиально отличается от False.
            # ---------------------------------------------------------------

            if versionlock_available:
                versionlocked = bool(matched_rules)
            else:
                versionlocked = None


            result.append({

                "package": name,

                "epoch": epoch,

                "version": version,

                "release": release,

                "arch": arch,

                "nevra": nevra,

                "versionlocked": versionlocked,

                "versionlock_rule": ",".join(
                    matched_rules
                ),
            })


        # ====================================================================
        # Стабильный порядок строк внутри сервера
        # ====================================================================

        result.sort(
            key=lambda x: (
                x["package"],
                x["version"],
                x["release"],
                x["arch"],
            )
        )


        print(
            json.dumps(
                result,
                ensure_ascii=False
            )
        )

        PY

      args:
        executable: /bin/bash

      register: audit_json

      changed_when: false
      failed_when: false

      when:
        - rpm_database_available | bool


    ###########################################################################
    #
    # 7. JSON -> ANSIBLE FACT
    #
    ###########################################################################

    - name: Save package audit
      ansible.builtin.set_fact:
        versionlock_audit: >-
          {{
            audit_json.stdout | from_json
          }}
      when:
        - rpm_database_available | bool
        - audit_json.rc | default(1) == 0


    ###########################################################################
    # Если обработка почему-то не удалась — создаём пустой список.
    #
    # Это НЕ создаст фиктивных package-строк в CSV.
    ###########################################################################

    - name: Initialize empty audit after processing error
      ansible.builtin.set_fact:
        versionlock_audit: []
      when:
        - versionlock_audit is not defined


    ###########################################################################
    #
    # 8. СОЗДАЁМ КАТАЛОГ НА CONTROLLER
    #
    # delegate_to:
    #   задача физически выполняется на Ansible controller.
    #
    # run_once:
    #   только один раз на весь play.
    #
    ###########################################################################

    - name: Create report directory on controller
      ansible.builtin.file:
        path: "{{ report_dir }}"
        state: directory
        mode: "0755"
      delegate_to: localhost
      become: false
      run_once: true


    ###########################################################################
    #
    # 9. СОЗДАЁМ ЕДИНЫЙ CSV
    #
    # КЛЮЧЕВОЕ ИЗМЕНЕНИЕ:
    #
    # Было:
    #
    #   groups['all']
    #
    # Это весь inventory и --limit на него не влияет.
    #
    # Теперь:
    #
    #   ansible_play_hosts
    #
    # Это активные хосты ИМЕННО ТЕКУЩЕГО PLAY,
    # с учетом --limit.
    #
    ###########################################################################

    - name: Generate central versionlock report
      ansible.builtin.copy:

        dest: "{{ report_file }}"

        mode: "0644"

        content: |
          host;package;epoch;version;release;arch;nevra;versionlock_was_installed;versionlock_install_status;versionlock_available;versionlocked;versionlock_rule
          {% for host in ansible_play_hosts | sort -%}
          {% for p in hostvars[host].versionlock_audit | default([]) -%}
          {{ host }};{{ p.package }};{{ p.epoch }};{{ p.version }};{{ p.release }};{{ p.arch }};{{ p.nevra }};{{ 'yes' if hostvars[host].versionlock_was_installed | default(false) else 'no' }};{{ hostvars[host].versionlock_install_status | default('unknown') }};{{ 'yes' if hostvars[host].versionlock_available | default(false) else 'no' }};{% if p.versionlocked is none %}unknown{% elif p.versionlocked %}yes{% else %}no{% endif %};{{ p.versionlock_rule | replace(';', ',') }}
          {% endfor -%}
          {% endfor -%}

      delegate_to: localhost
      become: false
      run_once: true


    ###########################################################################
    #
    # 10. РЕЗУЛЬТАТ
    #
    ###########################################################################

    - name: Show report information
      ansible.builtin.debug:
        msg:
          - "Versionlock report: {{ report_file }}"
          - "Hosts in report scope: {{ ansible_play_hosts | join(', ') }}"
      delegate_to: localhost
      run_once: true
      become: false
```

Теперь при таком inventory:

```ini
[servers]
srv01
srv02
srv03
srv04
srv05
srv06
```

и запуске:

```bash
ansible-playbook \
  -i inventory.ini \
  versionlock.yml \
  --limit 'srv02,srv04'
```

цикл формирования отчёта будет использовать фактически:

```yaml
ansible_play_hosts:
  - srv02
  - srv04
```

а не:

```yaml
groups['all']:
  - srv01
  - srv02
  - srv03
  - srv04
  - srv05
  - srv06
```

Именно поэтому прежний вариант давал ложные:

```text
unreachable_or_failed
```

для серверов, которые вы вообще не запускали через `--limit`.

Теперь такого поведения нет.

Если на `srv02` из списка установлены только:

```text
nginx
curl
openssl
```

а `postgresql`, `httpd`, `java-11-openjdk`, `python3` отсутствуют, в CSV появятся **только три строки**:

```text
host;package;epoch;version;release;arch;nevra;versionlock_was_installed;versionlock_install_status;versionlock_available;versionlocked;versionlock_rule
srv02;curl;0;7.76.1;...;x86_64;curl-0:7.76.1-....x86_64;yes;already_installed;yes;no;
srv02;nginx;0;1.20.1;...;x86_64;nginx-0:1.20.1-....x86_64;yes;already_installed;yes;yes;nginx-0:1.20.1-....*
srv02;openssl;1;1.1.1k;...;x86_64;openssl-1:1.1.1k-....x86_64;yes;already_installed;yes;no;
```

Отсутствующие пакеты вообще не упоминаются.

Ещё одно различие полезно держать в голове:

- `ansible_play_hosts_all` — все хосты, выбранные для **этого play с учётом `--limit`**, включая впоследствии упавшие/unreachable;
- `ansible_play_hosts` — хосты текущего play, которые к этому моменту остаются активными;
- `groups['all']` — **весь inventory**, `--limit` его содержимое не меняет.

Для вашего рабочего CSV я сознательно использовал `ansible_play_hosts`, чтобы реально недоступный по SSH сервер не создавал фиктивные строки с пакетами. Если нужно отдельно видеть серверы, которые попали под `--limit`, но оказались действительно unreachable, лучше сделать для них **отдельный маленький error-report**, а не смешивать их с отчётом по пакетам.
